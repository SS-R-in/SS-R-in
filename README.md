## Hi there 👋
**自我介绍**
    - 我来自**韶关**。
    - 我的兴趣爱好比较广泛，喜欢各种**运动**，游泳跑步跳绳。
    - 除了运动，我还痴迷于**钩织**手工艺，喜欢用毛线创造出各种可爱的小物件，从杯垫到玩偶，每个作品都充满了成就感。
    - 最喜欢的还是**动漫和漫画**，让自己处于不同世界的感觉非常奇妙。
    - 我十分享受**独处**的时光，在安静的环境中我能更好地专注于学习和创作。
